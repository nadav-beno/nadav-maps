# Nadav Maps

מפה ציבורית בסגנון Google Maps, בעברית, בנויה על נתוני [OpenStreetMap](https://www.openstreetmap.org/).
עולמית בתכנון, ישראל ראשונה. בלי מפתחות API.

**כתובת:** https://nadav-beno.github.io/nadav-maps/

## מה יש כבר

- עיצוב בסגנון Google Maps: לשוניות למטה (סביבה, שמורים, תרומה), סרגל חיפוש צף, צ'יפים, כפתורי פעולה עגולים, אייקוני Material
- מפה עולמית עם שמות בעברית, מצב כהה, התקנה כאפליקציה (PWA) באייפון ובאנדרואיד
- עשרות מיליוני עסקים מ-Overture Maps (טלפון, אתר, רשתות חברתיות) בנוסף ל-OpenStreetMap
- שכבות: מפת לוויין, פני שטח עם קווי גובה, תחבורה ציבורית, שבילי אופניים, תלת־ממד
- תנועה בזמן אמת ואירועי תנועה מ-HERE (גם בישראל) או מ-TomTom, וזמן נסיעה עם תנועה במסלולי רכב (כבוי עד שמגדירים מפתח, ראו [docs/data-sources.md](docs/data-sources.md))
- תיאור מוויקיפדיה בכרטיס של מקומות מוכרים
- חיפוש מקומות וכתובות (מבין קיצורים כמו ת"א, רח', פ"ת), קטגוריות קרובות (קפה, דלק, בתי מרקחת…)
- נתונים משלנו לישראל: חיפוש, כתובות עם מספר בית, "מה יש כאן" ופרטי מקומות מקבצים שנבנים כל שבוע מ-OpenStreetMap (דרך Geofabrik) ומתפרסמים עם האתר, בלי שרת ציבורי (Photon ו-Overpass נשארים לגיבוי ולחו"ל; ראו [docs/data-sources.md](docs/data-sources.md#our-own-geodata-self-hosted-israel))
- כרטיס מקום: כתובת, שעות פתיחה (פתוח/סגור עכשיו), טלפון, אתר, נגישות, תמונה, שיתוף
- מסלולים ברכב, ברגל ובאופניים, עם חלופות, הימנעות מכבישי אגרה ומהירים
- תחבורה ציבורית: מסלולים באוטובוס ורכבת עם החלפות, יציאה/הגעה בשעה מסוימת, וזמני יציאה קרובים בכל תחנה (Transitous)
- עצירות בדרך (עד 3), פרופיל גובה לרגל ולאופניים, פתיחת המסלול ב-Waze, ב-Google Maps או ב-Apple Maps
- חיפוש באזור הזה, סינון "פתוח עכשיו", הדבקת קישור מ-Google Maps או Waze, עסקים של Overture בתוצאות החיפוש
- כלים: מדידת מרחק ושטח, שמירת תמונה של המפה, קיצורי מקלדת
- ניווט קולי בעברית, מסך מלא, חישוב מסלול מחדש כשסוטים
- מועדפים, רשימות, בית ועבודה, היסטוריה, שיתוף רשימה בקישור, ייבוא וייצוא GeoJSON
- התמונות שלי על המפה (נשאר רק במכשיר), חלוקה אוטומטית לטיולים
- מצב טיסה: רואים את עצמכם על המפה במטוס בלי אינטרנט (GPS במצב טיסה): מהירות קרקע, גובה, כיוון, מעל איזו מדינה ועיר, מסלול שעברתם, יעד עם זמן נחיתה משוער, ומציאת הטיסה לפי מספר (ADS-B) כשיש Wi-Fi
- מפת עולם בסיסית שמורה באפליקציה (מדינות, גבולות, ערים גדולות): המפה אף פעם לא ריקה, גם בלי חיבור
- שרת MCP: Claude ועוזרים אחרים יכולים לחפש מקומות ולתכנן מסלולים

## הרצה מקומית

```bash
corepack enable
pnpm install
pnpm dev        # האתר
pnpm server     # שרת REST + MCP בפורט 8787
pnpm check      # כל הבדיקות והבנייה
pnpm geodata:fixture   # בונה מחדש את נתוני הבדיקה הקטנים (e2e/geodata) אחרי שינוי ב-scripts/geodata
```

הנתונים האמיתיים של ישראל נבנים רק ב-GitHub Actions (`scripts/geodata/build-all.sh`, צריך `osmium-tool`).
בפיתוח מקומי אין תיקיית `data/`, והאפליקציה עובדת מול Photon ו-Overpass. לשרת: `GEODATA_URL=https://nadav-beno.github.io/nadav-maps/data/`.

## חיבור Claude לשרת ה-MCP

אחרי שהשרת רץ בכתובת ציבורית, מוסיפים ב-Claude מחבר מותאם אישית עם הכתובת `https://<השרת>/mcp`.
